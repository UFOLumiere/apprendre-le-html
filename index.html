1. Apprendre le HTML

Le HTML est le langage qui permet de construire la structure d'une page Internet.

La structure de base

<!DOCTYPE html>
<html lang="fr">

<head>
    <title>Mon premier site</title>
</head>

<body>

    <h1>Bonjour !</h1>

    <p>Bienvenue sur mon site.</p>

</body>
</html>

Les principales balises HTML

  • <h1> : titre principal.
  • <h2> : sous-titre.
  • <p> : paragraphe.
  • <img> : image.
  • <a> : lien.
  • <ul> : liste.
  • <li> : élément d'une liste.
  • <button> : bouton.
  • <br> : saut de ligne.

Ajouter une image

<img src="image.jpg" alt="Description">

Créer un lien

<a href="https://www.google.com">
    Visiter Google
</a>

2. Apprendre le CSS

Le CSS permet de modifier l'apparence de ton site : couleurs, tailles, positions, arrière-plans...

Changer la couleur du texte

<style>
p {
    color: red;
}
</style>

Changer la couleur de fond

body {
    background-color: black;
}

Centrer un texte

h1 {
    text-align: center;
}

Modifier la taille d'un texte

p {
    font-size: 20px;
}

Créer un bouton personnalisé

button {
    background: purple;
    color: white;
    padding: 15px;
    border-radius: 10px;
}

3. Apprendre JavaScript

JavaScript permet de rendre ton site interactif. Tu peux créer des boutons, des jeux, des menus et bien plus !

Afficher un message

alert("Bienvenue sur mon site !");

Créer un bouton interactif

<button onclick="direBonjour()">
    Clique ici
</button>

<script>
function direBonjour() {
    alert("Bonjour !");
}
</script>

Changer un texte

<p id="message">Ancien texte</p>

<button onclick="changer()">
    Modifier
</button>

<script>
function changer() {
    document.getElementById("message")
    .textContent = "Nouveau texte !";
}
</script>
